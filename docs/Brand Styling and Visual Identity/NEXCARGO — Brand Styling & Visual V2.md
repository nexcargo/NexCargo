NexCargo — Brand Styling & Visual Identity Proposal

Version 1.0 | For Review by Chief Architect

1. Executive Summary

NexCargo operates at the intersection of logistics, financial technology, and AI-driven marketplace orchestration. The brand must communicate trust, precision, and innovation while remaining accessible to a diverse user base across the SADC region—from drivers with basic mobile phones to enterprise shippers and banking partners.

Core Brand Promise: Trust isn't a tagline—it's an outcome of repeatable, positive interactions.

This proposal outlines a comprehensive, modern brand styling system designed to be:

Operationally embedded—brand as infrastructure, not decoration

Culturally relevant—rooted in the SADC context while globally credible

Technically scalable—built for digital-first, mobile-heavy deployment

Accessible—WCAG-compliant and multilingual-ready

3. Visual Identity System

3.1 Logo Design

Design Concept: The Nexus Mark

The NexCargo logo should embody the platform's role as a connection hub between supply and demand, shippers and transporters, across borders.

Recommended Approach:

Symbol: A geometric mark combining:

A dynamic arrow or chevron representing movement and flow

A node/connection point representing the marketplace hub

Subtle overlapping forms suggesting cross-border connectivity

Inspiration: Clean geometric marks symbolising direction, flow, and connection are hallmarks of modern logistics branding. The mark should work at small sizes (mobile apps) and large (billboards).

Logo Variations:

Variant	Usage
Primary (Full)		Brand mark + wordmark, for most applications
Symbol Only		Favicon, app icon, social avatar
Wordmark Only		Headers where symbol is redundant
Monochrome		Print, engraving, limited-ink scenarios

Clear Space: Minimum clear space equal to the height of the wordmark.

Minimum Size:

Digital: 32px height for symbol, 48px for full logo

Print: 0.5 inch for symbol, 1 inch for full logo

Strategic Rationale: Logistics is dominated by blues (FedEx, DHL, UPS). NexCargo will differentiate through a considered palette that balances trust with energy and regional relevance.

Accessibility: All color combinations must meet WCAG AA minimum contrast (4.5:1 for text, 3:1 for UI components). The palette has been selected with this in mind.

Cultural Warmth Principle: Cultural warmth for Mozambique/SADC should be expressed primarily through imagery and visual storytelling—not through locale-dependent functional UI colours. Photography, illustrations, campaign imagery, marketing composition, and contextual visual storytelling are appropriate vehicles for cultural expression. Functional elements such as buttons, navigation, status indicators, errors, warnings, financial states, controls, and system feedback must retain the same semantic colour system regardless of locale. One coherent NexCargo functional design system; cultural warmth expressed through imagery and content rather than locale-dependent functional colours.

3.3 Typography

Primary Typeface: Inter

Inter is an open-source, highly legible sans-serif designed for screens. It offers excellent readability at small sizes, supports multiple languages (including Portuguese and English), and conveys a modern, technical precision.

Usage: UI, body text, documentation, forms

Weights: 300 (Light), 400 (Regular), 500 (Medium), 600 (Semi-Bold), 700 (Bold)

Fallback: system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif

Display Typeface: Space Grotesk

A bold, geometric display font for headings, hero text, and marketing materials. Conveys confidence and forward momentum.

Usage: Headings (H1-H3), hero text, marketing

Weights: 500 (Medium), 600 (Semi-Bold), 700 (Bold)

Fallback: Inter (same weights)

Wordmark Treatment: Orbitron is reserved specifically for the NexCargo wordmark treatment, if/when the approved wordmark uses it. Do not use Orbitron as a general UI or body font, nor as a replacement for Space Grotesk in headings or display typography.

3.4 Imagery & Photography

Style Principles:

Authentic: Real people, real logistics environments—not stock perfection

Regional: SADC context—Mozambique, South Africa, Zimbabwe, Zambia

Action-oriented: Movement, loading, driving, delivering

Human-centric: Faces of drivers, dispatchers, shippers

Image Treatment:

Consistent color grading (warm shadows, balanced highlights)

Natural lighting, no heavy filters

Overlay gradients for text legibility (navy with 60-80% opacity)

People always looking engaged, not posed

Sourcing: Commissioned photography preferred. Stock imagery from African-focused collections (e.g., Pexels Africa, iStock's African collections) as fallback.

Filled Variants: For active states, selected items, primary actions

Color: Primary blue for standard, signal orange for alerts, gray for disabled

Icon Categories:

Category	Examples

Marketplace	Listing, bid, match, contract, handshake
Financial	Escrow, wallet, settlement, lock, release
AI	Brain, sparkle, chart, prediction, recommendation
Communication	Message, notification, alert, call
Admin	Shield, key, audit, settings, user
3.6 Illustration Style
For empty states, onboarding, and marketing:

Style: Flat, geometric illustrations with limited color palette

Palette: Navy base + blue + orange accents + white space

Content: Abstract representations of logistics flows, connections, and marketplaces

Tone: Warm, approachable, never cold or corporate

4.4 Motion & Animation
Principles:

Purposeful, not decorative

200-300ms duration for micro-interactions

400-600ms for transitions

Easing: cubic-bezier(0.4, 0, 0.2, 1) (standard ease)

Applications:

Loading states: skeleton screens, spinners

State transitions: slide, fade

Feedback: success/failure animations

Navigation: smooth page transitions

6. Accessibility Standards

NexCargo's brand styling must comply with WCAG 2.1 AA minimum:

Requirement	Implementation
Colour contrast	4.5:1 for text, 3:1 for UI (verified in palette)
Focus indicators	Visible 2px outline (#1A5C9E or #E85D2A)
Touch targets	Minimum 44x44px for interactive elements
Font sizes	Minimum 16px for body text
Spacing	1.5x line height for body, 1.2x for headings
Keyboard navigation	Full support, visible focus
Screen readers	Semantic HTML, ARIA labels, alt text
